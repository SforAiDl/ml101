Part 1Why Not Dense Layers for Images?

  • Loss of spatial structure: Flattening 2D images into 1D vectors destroys pixel adjacency, discarding shapes, lines, and textures.
  • Parameter explosion: Connecting every pixel to hidden units produces millions of weights, causing severe memory overhead and overfitting.
  • No spatial weight sharing: Shifting an object forces dense layers to relearn it from scratch, as weights are tied to fixed pixel coordinates.

Part 2The Convolution Operation & ReLU

  • Filter (Kernel): A small matrix of weights (e.g. 3 × 3) that slides over pixels to detect visual features.
  • Stride (S): The step size in pixels the filter shifts horizontally and vertically across the image.
  • Padding (P): Extra border pixels (usually zeros) added around image edges to prevent spatial shrinkage.
  • Feature Map: The 2D output grid storing the dot-product response at each filter position.
  • ReLU: Non-linear activation ReLU(x) = max(0, x) that zeros out negative values.

Part 3Feature Hierarchies

  • Hierarchical abstraction: Early layers detect raw visual primitives; deeper layers compose them into complex semantics.
  • Layer 1 (Low-level): Extracts oriented edges, color-opponent contrasts, and basic gradient bars.
  • Layer 2 (Mid-level): Combines edges into corners, textures, curves, and surface patterns.
  • Layer 3+ (High-level): Assembles mid-level contours into recognizable object parts (wheels, windows, faces).

Part 5Batch Normalization

  • Internal covariate shift: Upstream parameter updates cause downstream feature distributions to drift continuously.
  • Mini-batch standardization: Normalizes each feature dimension across the batch to zero mean and unit variance.

Part 5bBatchNorm in CNNs (4D Tensors)

  • 4D tensor dimensions: Convolutional activations form a 4D tensor of shape N × C × H × W.
  • Channel-wise pooling: Computes one mean μc and variance σc2 across all N × H × W activations for each channel.
  • Consistent spatial scaling: Adheres to convolutional weight sharing by scaling all pixels in a channel identically.
